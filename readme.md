# Face Alignment

Скрипт для **Adobe Photoshop**, который автоматически выравнивает слои по лицу или фигуре человека. Использует Google MediaPipe для определения ключевых точек и дополнительную модель контура человека для мягкой корректировки размера головы.

## 🚀 Основные возможности

* **Head & Shoulders:** Выравнивание по лицу. Размер рассчитывается по нескольким измерениям с уменьшением влияния ошибочных значений.
* **Half Body:** Выравнивание по фигуре до линии бёдер.
* **Full Body:** Выравнивание во весь рост.
* **Автоматический выбор режима:** Определение крупности плана и выбор подходящего режима выравнивания.
* **Контур головы:** Дополнительный ориентир для небольшой поправки масштаба в погрудном режиме. Его можно отключить.

---

## 🛠 Системные требования

* **Windows 10/11, 64 бит (x64).**
* **Adobe Photoshop 2019 и новее.**
* Интернет для первой установки Python, зависимостей и моделей. Дальнейшая обработка фотографий выполняется локально.

Устанавливать системный Python или добавлять его в **PATH** не требуется. Скрипт использует собственное окружение с Python 3.11.16, которое не меняет зависимости других программ.

## 📥 Установка и настройка

### Шаг 1. Установка окружения (один раз)

1. Распакуйте архив целиком.
2. Запустите [install_runtime.bat](./install_runtime.bat).
3. Выберите **1 — Normal secure mode**. Если антивирус Kaspersky мешает загрузке пакетов, в установщике предусмотрен отдельный режим совместимости.
4. Дождитесь сообщения **Installation complete**.

Установщик автоматически создаёт отдельное окружение, загружает четыре модели и проверяет их работу.

Python и зависимости находятся в:
`%LOCALAPPDATA%\FaceAlignmentRuntime\venv`

Модели находятся в:
`%LOCALAPPDATA%\FaceAlignmentRuntime\venv\models`

Если запустить JSX непосредственно из распакованного пакета до установки, он откроет установщик автоматически. Завершите установку в появившемся окне.

### Шаг 2. Копирование файлов в Photoshop

Скопируйте **содержимое** папки `Photoshop-files` в папку `Presets\Scripts` вашей версии Photoshop, например:
`C:\Program Files\Adobe\Adobe Photoshop 2026\Presets\Scripts\`

**Необходимые файлы в папке Scripts:**

* **Face alignment.jsx** — основной скрипт.
* **lib/face-detect-api.pyw** — фоновый сервер обработки.

Модели копировать в Photoshop не нужно: они уже находятся в отдельном окружении.

Перезапустите Photoshop, чтобы скрипт появился в меню. Также JSX можно запустить через **Файл → Сценарии → Обзор**.

При обновлении заменяйте **оба файла — JSX и PYW**. Сохраните распакованный пакет: `install_runtime.bat` можно повторно запустить для проверки и восстановления окружения.

## 🕹 Как использовать

1. Откройте документ и выберите **минимум 2 незаблокированных слоя**.
   * **Нижний из выбранных слоёв** — эталон, к которому выполняется подгонка.
   * **Остальные выбранные слои** — фотографии для выравнивания.
2. Перейдите в меню **Файл → Сценарии → Face alignment** (File → Scripts).
3. Выберите режим, настройте нужные операции и запустите выравнивание.

При первом обращении к серверу может потребоваться дополнительное время на запуск Python и загрузку моделей.

### Основные параметры

* **fit central points of faces** — совмещение центральных точек лица.
* **size matching** — подгонка масштаба по найденным ключевым точкам.
* **use head contour (small scale adjustment)** — мягкая поправка масштаба по контуру головы. Работает только в погрудном режиме при включённой подгонке размера.
* **aligning the eyes horizontally** — коррекция наклона линии глаз.
* **match reference head tilt** — учёт наклона головы образца вместо выравнивания линии глаз по горизонтали.
* **Rotation Ratio** — степень коррекции наклона головы; значение по умолчанию — 0,75.
* **Interactive Transform** — показ рамки трансформации для ручной корректировки каждого слоя.
* **Resize for detector** — размер уменьшенной копии фотографии для анализа.

Настройки сохраняются между запусками. Параметры выравнивания можно записывать в операции Photoshop (Actions).

## 💡 Особенности работы

* **Масштаб лица:** В погрудном режиме используются шесть измерений. Сильно расходящиеся оценки исключаются или получают меньший вес.
* **Контур головы:** Основой остаются ориентиры лица. Поправка по контуру ограничена примерно 2,5%. При обрезанной макушке, ненадёжном контуре или сильном расхождении оценок она пропускается. Причёска и головные уборы могут влиять на результат.
* **Фоновый сервер:** Запускается автоматически и завершает работу через **15 минут простоя**.
* **Совместная работа:** Face Alignment использует собственное окружение и отдельные порты, поэтому не конфликтует с сервером Align and fit layers.
* **Smart Objects:** Для анализа создаётся растровая копия; исходное содержимое смарт-объекта не редактируется.
* **Временные файлы:** После успешного анализа временные JPEG удаляются.

Если сервер не запускается, повторите установку через `install_runtime.bat`. Подробности ошибок сервера записываются в:
`%LOCALAPPDATA%\FaceAlignmentRuntime\server.log`
