# Photoshop Face Alignment Script

Система автоматического выравнивания лиц в Adobe Photoshop. Скрипт использует библиотеку **MediaPipe Face Mesh** для поиска 468 ключевых точек лица и их последующего совмещения на разных слоях.

---

## 📦 Состав проекта

* [**Face alignment.jsx**](./Face%20alignment.jsx) — Скрипт для Photoshop. Управляет слоями и выполняет трансформацию.
* [**face-detect-api.pyw**](./face-detect-api.pyw) — Локальный сервер на Python для работы нейросети в фоновом режиме.
* [**install_packages.bat**](./install_packages.bat) — Скрипт для установки зависимостей и загрузки модели.
* `lib/face_landmarker.task` — Модель данных MediaPipe (загружается автоматически).

---

## ⚠️ Требования к системе

Для работы скрипта на компьютере должен быть установлен **Python**:
* **Версия:** от **3.8** до **3.12** (MediaPipe на данный момент стабильно работает в этом диапазоне).
* **Настройка:** При установке Python обязательно должна быть включена опция **"Add Python to PATH"**.
* **Проверка:** Команда `python --version` в консоли должна возвращать номер версии.

## 🚀 Установка и настройка

### 1. Размещение файлов
Скопируйте все файлы проекта и папку `lib` в директорию скриптов Photoshop.  
**Для Photoshop 2026 путь по умолчанию:** `C:\Program Files\Adobe\Adobe Photoshop 2026\Presets\Scripts\`

### 2. Установка зависимостей
Запустите [**install_packages.bat**](./install_packages.bat) **от имени администратора**.  
Так как Photoshop установлен в защищенную системную папку `Program Files`, права администратора необходимы для:
* Установки библиотек `mediapipe`, `opencv-python` и `numpy` в системный Python.
* Создания папки `lib` и загрузки в неё модели `face_landmarker.task` через PowerShell.

### 3. Использование
1. Откройте документ и выберите **2 или более разблокированных слоя**.
2. **Нижний слой** является базовым — по его размеру и положению лица будут выравниваться остальные.
3. Запустите: `Файл` → `Скрипты` → **Face alignment**.

## ⚙️ Настройки в JSX

В начале файла [**Face alignment.jsx**](./Face%20alignment.jsx) можно изменить параметры работы:

| Параметр | Описание | По умолчанию |
| :--- | :--- | :--- |
| `moveMode` | Выравнивание позиции центра лица | `true` |
| `transformMode` | Масштабирование под размер базового лица | `true` |
| `rotateMode` | Коррекция наклона головы (горизонт) | `true` |
| `angle_ratio` | Коэффициент силы поворота (0.0 — 1.0) | `0.75` |
| `detect_size` | Макс. размер изображения для анализа | `1024` |

## 🔬 Технические детали

* **Взаимодействие:** JSX-скрипт отправляет путь к временному файлу на локальный сервер через TCP-порт `6310`. Сервер возвращает координаты точек через порт `6311`.
* **Фоновый процесс:** Python-сервер запускается автоматически при вызове скрипта и завершает работу после **5 минут** отсутствия запросов.
* **Очистка:** Временные JPEG-файлы, созданные для анализа, удаляются скриптом сразу после получения координат.

## 🛠 Устранение проблем

* **Ошибка "python не является внутренней командой":** Python не добавлен в переменные среды PATH. Переустановите Python с соответствующей галочкой.
* **Ошибка доступа (Access Denied):** Запустите `.bat` файл от имени администратора.
* **Лицо не найдено:** Убедитесь, что лицо на базовом слое освещено и расположено анфас или в полуанфас.
* **Задержка запуска:** Первая инициализация нейросети может занять до 15 секунд.
