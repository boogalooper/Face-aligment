# Face Alignment

Скрипт для **Adobe Photoshop**, который автоматически выравнивает слои по лицу или фигуре человека. Использует нейросети Google MediaPipe для определения ключевых точек лица и тела.

## 🚀 Основные возможности

* **Head & Shoulders:** Выравнивание по лицу (глаза, нос, овал лица с учетом небольшого поворота головы).
* **Half Body:** Выравнивание по торсу (до линии бёдер).
* **Full Body:** Выравнивание во весь рост.
* **Автоматическое выравнивание:** Определение крупности плана и автоматический выбор режима выравнивания.

## 🛠 Системные требования

### Photoshop

* Версия **2019** и новее (протестировано на актуальной версии 2026).

### Python

* Устанавливается автоматически в отдельную папку. Устанавливать Python вручную и настраивать **PATH** не нужно.
* Для установки необходимы **Windows 10/11 x64** и интернет.

## 📥 Установка и настройка

### Шаг 1. Установка зависимостей (один раз)
1. Распакуйте архив и запустите [install_runtime.bat](./install_runtime.bat).
2. Выберите **1 — Normal secure mode** и дождитесь сообщения **Installation complete**.

Установщик сам загрузит Python, необходимые библиотеки и модели. Они хранятся отдельно от Photoshop в `%LOCALAPPDATA%\FaceAlignmentRuntime`.

### Шаг 2. Копирование файлов в Photoshop
Скопируйте содержимое папки **Photoshop-files** в папку `Presets\Scripts` вашей версии Photoshop, например:
`C:\Program Files\Adobe\Adobe Photoshop 2026\Presets\Scripts\`

**Необходимые файлы в папке Scripts:**

* **Face alignment.jsx** — основной скрипт.
* **lib/face-detect-api.pyw** — фоновый сервер обработки.

Затем перезапустите Photoshop. Модели копировать не нужно.
При обновлении заменяйте JSX и PYW из нового архива.

## 🕹 Как использовать

1. Откройте Photoshop и выберите **минимум 2 слоя**.
   * **Нижний из выбранных слоёв** — эталон (образец, к которому подгоняем).
   * **Верхние слои** — те, что будут выровнены по эталону.
2. Перейдите в меню: **Файл → Скрипты → Face alignment** (File → Scripts).
3. При первом запуске может потребоваться несколько секунд для старта сервера.

### Основные параметры:

* **fit central points of faces** Совмещение центральных точек лица (если выключено - слой остается на месте)
* **size matching** Подгонка фотографий по размеру с учетом найденных ключевых точек (если выключено - размер не меняется)
* **use head contour (small scale adjustment):** Небольшая поправка размера по контуру головы в погрудном режиме. Основой остаются ориентиры лица.
* **aligning the eyes horizontally** Коррекция наклона линии глаз, скрипт стремится сделать линию глаз горизонтальной
* **match reference head tilt:** Выравнивание с учётом наклона головы образца.
* **Rotation Ratio:** Коэффициент компенсации наклона головы (0.75 — для естественного результата).
* **Interactive Transform:** Активация прямоугольника трансформации. Позволяет вручную поправить каждый слой в процессе работы скрипта.
* **Resize for detector:** Размер (в пикселях), до которого сжимается копия фото для анализа.

## 💡 Особенности работы

* **Фоновый сервер:** Python-сервер запускается автоматически, используется повторно и завершает работу через 15 минут простоя для экономии ресурсов.
* **Слои:** Работайте только с разблокированными (unlocked) слоями.
* **Smart Objects:** Скрипт анализирует растровую копию смарт-объекта, не повреждая оригинал.
* **Временные файлы:** Все промежуточные данные в папке `TEMP` удаляются автоматически.
