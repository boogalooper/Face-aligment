# Face Alignment

Скрипт для **Adobe Photoshop**, который автоматически выравнивает слои по лицу или фигуре человека. Использует нейросети Google MediaPipe для определения антропометрических точек.

## 🚀 Основные возможности
* **Head & Shoulders:** Выравнивание по лицу (глаза, нос, овал лица с учетом небольшого поворота головы).
* **Half Body:** Выравнивание по торсу (до линии бёдер).
* **Full Body:** Выравнивание во весь рост.
* **Автоматическое выравнивание:** Определение крупности плана и автоматический выбор режима выравнивания.

## 📥 Установка и настройка

### Шаг 1. Установка зависимостей (один раз)
Перед использованием скрипта необходимо установить библиотеки MediaPipe и OpenCV:
1. Запустите файл [install_packages.bat](./install_packages.bat) из папки репозитория.
2. Дождитесь завершения установки. После этого файл `.bat` можно удалить.

### Шаг 2. Копирование файлов в Photoshop
Переместите следующие файлы и папки в директорию пресетов вашего Photoshop:
`C:\Program Files\Adobe\Adobe Photoshop\Presets\Scripts\`

**Необходимые файлы в папке Scripts:**
* [Face alignment.jsx](./Face%20alignment.jsx) — основной скрипт.
* [face-detect-api.pyw](./face-detect-api.pyw) — фоновый сервер обработки.
* **lib/** — папка с моделями (обязательно должна быть рядом со скриптом):
    * [face_landmarker.task](./lib/face_landmarker.task)
    * [pose_landmarker_heavy.task](./lib/pose_landmarker_heavy.task)

## 🕹 Как использовать

1. Откройте Photoshop и выберите **минимум 2 слоя**.
   * **Нижний слой** — эталон (образец, к которому подгоняем).
   * **Верхние слои** — те, что будут выровнены по эталону.
2. Перейдите в меню: **Файл → Скрипты → Face alignment** (File → Scripts).
3. При первом запуске может потребоваться несколько секунд для старта сервера.

### Основные параметры:
* **fit central points of faces** Совмещение центральных точек лица (если выключено - слой остается на месте)
* **size matching** Подгонка фотографий по размеру с учетом найденных ключевых точек (если выключено - размер не меняется)
* **aligning the eyes horizontally** Коррекция наклона линии глаз, скрипт стремится сделать линию глаз горизонтальной
* **Rotation Ratio:** Коэффициент компенсации наклона головы (0.75 — для естественного результата).
* **Interactive Transform:** Активация прямоугольника трансформации. Позволяет вручную поправить каждый словй в процессе работы скрипта.
* **Resize for detector:** Размер (в пикселях), до которого сжимается копия фото для анализа.

## 💡 Особенности работы
* **Фоновый сервер:** Python-сервер запускается автоматически и завершает работу через 5 минут простоя для экономии ресурсов.
* **Слои:** Работайте только с разблокированными (unlocked) слоями.
* **Smart Objects:** Скрипт анализирует растровую копию смарт-объекта, не повреждая оригинал.
* **Временные файлы:** Все промежуточные данные в папке `TEMP` удаляются автоматически.
